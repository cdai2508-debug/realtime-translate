Deepgram APIキーの取得方法
  1. console.deepgram.com でアカウント作成
  2. Dashboard → API Keys → Create a New API Key
  3. 作成されたキーをコピーして上に貼り付け
DeepL APIキー（必須）
DeepL APIキーの取得方法
  1. deepl.com/ja/pro-api にアクセス
  2. 無料アカウントを作成（Free プランで月50万文字まで無料）
  3. アカウント設定ページでAPIキーをコピー
  4. 上のフィールドに貼り付け
